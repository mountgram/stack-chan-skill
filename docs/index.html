A full-feature demo app is embedded.

Agents do not have to begin from a blank folder. The skill ships a Bun and TypeScript starter at assets/fullstack-agent/ that shows how a real StackChan brain server is put together.

$ open assets/fullstack-agent/

> routes: health, prompt, voice, render

> device: registry, protocol, commands, safety tests

> UI: debug terminal and render simulator

> agent: tools, prompt, Stacky behavior hooks

> voice: Deepgram live input, streaming TTS, wake-word hooks

  • Brain server starterAgents can copy the server shape into your project, then adapt routes, tools, memory, and provider choices.
  • Debug terminalA browser control panel for prompts, body commands, face presets, rendered faces, decorators, camera captures, state, and event logs.
  • Render simulatorA local 320 by 240 scene editor for JSON faces, animation tracks, bounds, presets, and device-send commands.
  • Command safetyTests and helpers show agents how to validate device commands before they reach motors, audio, LEDs, or render state.
  • Voice plumbingDeepgram live speech input and streaming TTS are included as working integration points, ready for your own keys.
  • On-device wake wordThe firmware path has a place for local wake-word behavior so StackChan can listen for a trigger before handing speech to the brain server.
  • Agent toolsThe demo app includes AI SDK tool wiring so StackChan can respond through real server-side actions instead of canned page tricks.
